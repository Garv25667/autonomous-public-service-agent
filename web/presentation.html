The Challenge

The Crushing Friction of Digital Bureaucracy

While India has digitized thousands of public services, navigating them remains hostile for ordinary citizens.

🏛️
Fragmented Portals
Over 500+ disparate central and state portals (Parivahan, NSP, State RTOs) with conflicting UI patterns and legacy technology stacks.

Millions are forced to hand over original Aadhaar cards, OTPs, and PAN cards to unregulated cyber cafés, causing identity theft.

Engineering Deep-Dive

End-to-End System Architecture

Dual-loop agentic framework combining LLM reasoning with an isolated desktop browser actuator.

🛡️
Zero-PII Perception & Privacy Layer
• Local Secret Vault: Tokens like {{CITIZEN_AADHAAR_TOKEN}} replace real numbers before calling Gemini API.
• Local OCR & Parser: PyMuPDF / Tesseract running offline to ingest marksheets and DL scans without cloud leaks.
• Statutory Rule Engine: Deterministic YAML rule evaluation (Motor Vehicles Act Form 1A age thresholds, CSS income caps).
🚀
Autonomous Actuation Engine
• Headed Chromium Actuator: Real Playwright engine operating with 400ms slow-mo and visual element highlighting.
• Windows Proactor Worker: Thread-isolated event loop avoiding event-loop blocking on Windows workstations.
• Real-Time WebSocket Stream: Broadcasts agent reasoning thoughts, DOM field mappings, and verified receipts to UI.

Safety & Reliability

Enterprise Safety & Guardrail Innovations

Engineered with defense-in-depth to guarantee compliance with Indian digital privacy and security laws.

🔒
Zero-Hallucination Policy
The agent strictly refuses to invent or guess applicant fields. If required data is missing from the vault, it halts and asks the citizen.
🤝
Human-in-the-Loop Contract
Never attempts to bypass CAPTCHA, brute force OTPs, or auto-submit statutory declarations. Explicit consent required before final submission.
📜
Cryptographic Receipt Trail
Generates tamper-evident timestamped receipts with application reference IDs (e.g. DL-RJ01-2026-904821) for auditability.
